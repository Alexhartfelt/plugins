### Changed

- `support-debugging` now carries its whole opening contract itself, so a pasted ticket no longer
  has to spell it out. It settles the customer, the website and the feature with the operator in
  its first reply — on every ticket, including when the ticket already states them — asks for every
  unresolved field in that same message, and waits before investigating. It never picks a website
  itself or infers one from the mail text; it shows the customer's site list and lets the operator
  choose.
