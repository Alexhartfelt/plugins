# Pages Cheat Sheet
Cheat sheet for [Hello Retail Pages](../../features/pages/pages.md) — dynamic, personalized category and brand pages. Drop new snippets into the file that matches the platform scope; see [../README.md](../README.md) for the convention.

## Files

- [general.md](./general.md) — platform-agnostic Pages snippets (test-div for previewing drafts, hide irrelevant filters, polling helper, Pages REST API request shapes, `extraDataList` syntax in `data-filters`)
- [shopify.md](./shopify.md) — Shopify-specific (where to insert the Pages div, auto-sort "newest" by date)
- [magento.md](./magento.md) — Magento-specific (remove customer's product list when Pages renders)
- DanDomain Classic has no local snippets; follow [How to Set Up Pages for DanDomain Classic](https://support.helloretail.com/pages/how-to-set-up-pages-for-dandomain-classic/).
